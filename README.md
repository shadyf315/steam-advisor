# 🎮 Steam Advisor

> **Умный помощник, который анализирует твою Steam-библиотеку и подбирает игру, в которую действительно хочется поиграть.**

Steam Advisor анализирует игры, которыми ты уже владеешь, учитывает время, проведённое в них, твои предпочтения, жанры и выбранное настроение — а затем предлагает подходящую игру.

## ✨ Возможности

* 🎮 **Два режима рекомендаций**

  * 📚 Из моей библиотеки
  * 🌎 Из всего Steam
* 🤖 AI-анализ игровой библиотеки
* ⏱️ Анализ времени, проведённого в играх
* 🎯 Определение игровых предпочтений
* 🧠 Учитывание выбранного настроения
* 🎭 Большое количество жанров
* 🔎 Поиск игр по всему Steam
* 🚫 Исключение уже купленных игр в глобальном режиме
* ✅ Фильтрация ещё не вышедших игр
* 👤 Поддержка Steam-профиля и SteamID64
* 🖼️ Изображения игр из Steam
* 🔗 Прямые ссылки на страницы игр
* ⏳ Красивый экран загрузки с этапами анализа
* 📱 Адаптация под мобильные устройства
* 🎃 Halloween Edition с атмосферным фоном

## 🕹️ Как это работает

1. Вставь ссылку на свой Steam-профиль.
2. Выбери режим рекомендаций.
3. Выбери настроение.
4. Укажи желаемую продолжительность игры.
5. При необходимости выбери жанр и количество игроков.
6. Нажми **«Найти игру»**.
7. Steam Advisor проанализирует данные и предложит игру.

### 📚 Режим «Из моей библиотеки»

Система ищет подходящую игру среди игр, которыми ты уже владеешь.

Это удобно, если на аккаунте много купленных игр, до которых так и не дошли руки.

### 🌎 Режим «Из всего Steam»

Steam Advisor ищет подходящие игры за пределами твоей библиотеки.

При этом уже имеющиеся у тебя игры исключаются из рекомендаций.

## 🤖 AI

AI используется для анализа предпочтений пользователя и выбора наиболее подходящей игры из найденных кандидатов.

Если AI недоступен, система может использовать локальную систему оценки игр в качестве резервного варианта.

## 🔐 Безопасность

API-ключи не хранятся в `index.html`.

Frontend обращается к Cloudflare Worker, а секретные ключи хранятся в настройках Worker.

Это позволяет не публиковать секретные ключи вместе с сайтом.

## 🚀 Запуск проекта

### Frontend

Проект можно разместить на GitHub Pages.

После публикации сайт работает полностью в браузере и обращается к Cloudflare Worker для получения рекомендаций.

### Cloudflare Worker

Worker отвечает за:

* получение Steam-профиля;
* получение библиотеки игр;
* анализ игрового времени;
* поиск кандидатов;
* получение информации об играх;
* AI-анализ;
* формирование результата.

## ⭐ Идея проекта

Steam Advisor создан для простой ситуации:

> **«У меня куча игр в Steam, но я вообще не знаю, во что сегодня играть».**

Вместо бесконечного пролистывания библиотеки сервис анализирует твои предпочтения и пытается найти игру, которая подходит именно под твоё настроение.
