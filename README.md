# 🎮 Steam Advisor

Умный подбор игр из твоей библиотеки Steam с помощью AI.

Steam Advisor анализирует игры в твоём Steam-профиле и помогает выбрать, во что поиграть прямо сейчас.

## ✨ Возможности

- 🎮 Получение игр из библиотеки Steam
- 🤖 AI-рекомендации
- 🎭 Выбор настроения
- ⏱️ Выбор продолжительности игры
- 🏷️ Фильтр по жанру
- 👥 Выбор игры для одного или с друзьями
- 🖼️ Красивые карточки игр
- 🔗 Быстрый переход на страницу игры в Steam
- 🌐 Работает через GitHub Pages

## 🛠️ Технологии

- HTML
- CSS
- JavaScript
- Steam Web API
- Cloudflare Workers
- OpenAI API
- GitHub Pages
